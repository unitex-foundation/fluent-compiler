# Info

This is a partial list of people and companies that have contributed to this project. It is sorted alphabetically by name. Required fields are `name` and `email`, all the rest is added as you desire and must follow this order and format:

```
// as an individual

- **Full Name in English** (Full Name in native language) // English required (Native optional)
- email: list of email addresses                          // required at least one, separated by ","
- nickname: list of nicknames                             // optional, separated by ","
- web: list of web addresses                              // optional, separated by ","
- social: list of social links                            // optional, separated by ","

// as a company

- **Short Company Name in English** (Long Company Name in English)           // required
- Short Company Name in other language (Long Company Name in other language) // optional
- web: list of web addresses                                                 // required at least one, separated by ","
- email: list of email addresses                                             // required at least one, separated by ","
- social: list of social links                                               // optional, separated by ","
- phone: list of phone numbers                                               // optional, separated by ","
- address: legal address                                                     // optional, format: country, postcode, state, city, street, building, office
- authors: list of authors                                                   // required at least one, must be present in "Individuals" section, separated by ","
```

Example:

```
// as an individual

- **John Smith** (Иван Кузнецов)
- email: john.smith@example.com
- nickname: john_smith
- web: [John Smith](john.smith.example.com)
- social: [telegram](example.com), [discord](example.com), [github](example.com)

// as a company

- **Example LLC** (Example Limited Liability Company)
- **ООО «Пример»** (Общество с ограниченной ответственностью «Пример»)
- web: [example.com](example.com)
- email: contact@example.com
- social: [telegram](example.com), [discord](example.com), [github](example.com)
- phone: +XXXXXXXXXXX
- address: country, postcode, state, city, street, building, office
- authors: John Smith
```

Add yourself and your employer (if it holds a copyright to your contribution) into the list.

This list may also be populated later automatically based on the accepted contributions.
